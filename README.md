# Bhanvi Solar — Frontend

Next.js 16 (App Router) frontend for the Bhanvi Solar platform. See the
[root README](../README.md) for full setup instructions, environment variables, architecture
notes, and deployment guidance.

Quick start:

```bash
cp .env.example .env.local
npm install
npm run dev   # http://localhost:3000 — requires the backend running (see ../backend)
```
